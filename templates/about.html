Smart Traffic Detection and Monitoring System

Objective

To detect vehicles automatically and monitor traffic conditions using computer vision and machine learning.

Problem statement

Counting vehicles by hand is slow, tiring and inconsistent. Cities need a quick, repeatable way to measure how busy a road is, so signals and diversions can be planned with real numbers.

Objectives

  • Detect cars, motorcycles, buses and trucks in images and videos.
  • Rate traffic as Normal, Moderate, Heavy or Critical from the vehicle count.
  • Read traffic-light state where it is clearly visible.
  • Present stored traffic records in a dashboard, charts and a searchable table.

Methodology

  1. The user uploads an image or video through the web page.
  2. Flask validates the file and saves it with a secure name.
  3. OpenCV reads the frames and the YOLOv8n model detects objects.
  4. Detections above the confidence threshold are counted by class.
  5. The total sets the traffic level; traffic-light colour is read from its pixels.
  6. The annotated result is saved in the results folder and shown on the page.
  7. Pandas reads traffic_detection.csv to power the dashboard, charts and table.

Advantages

  • Fast and consistent compared with manual counting.
  • Runs on an ordinary laptop with the lightweight YOLOv8n model.
  • Honest results: an unclear traffic light is reported as Not Detected.
  • Built on free, open-source tools.

Future scope

  • Live camera and CCTV stream input.
  • Vehicle tracking to count each vehicle once across a video.
  • Number-plate recognition and speed estimation.
  • Database storage and automatic alerts for Critical traffic.
  • Adaptive signal timing based on detected congestion.
